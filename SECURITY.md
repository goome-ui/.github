<h1 align="center">🛡️ Security Policy 🛡️</h1>
<p align="center">
If you found a vulnerability or exploit in anything goome, please handle it safely and tell me privately first.<br>
That means stuff like a crash or out of bounds read from a bad PNG, JPEG, BMP, QOI or font file, someone else writing into the control fifo, or anything that lets another user or app send fake input to an overlay.<br> <br>
Secure GitHub Forms: use the one in the repo its in, <code>https://github.com/goome-ui/&lt;repo&gt;/security/advisories/new</code><br>
For the C library thats https://github.com/goome-ui/c-goome/security/advisories/new <br>
Not sure which repo? Use the c-goome one.<br> <br>
Discord: https://sevvy-wevvy.com/discord <br>
Email: <code>sev@3gv.org</code>
</p>

> [!CAUTION]
> Please do not post any found vulnerabilities or exploits publicly anywhere before they're fixed.
> Sharing them after they are patched is fine, as long as there is no way to recreate them.
